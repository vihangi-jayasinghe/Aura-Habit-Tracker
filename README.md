## Description 🌟

Aura-Habit-Tracker is a modern self-care Android app designed to help users build healthier daily routines by tracking hydration, habits, and mood. It provides a user-friendly interface with features like:

- **Mood Tracking**: Log your mood daily with associated emojis and notes. 😃
- **Habit Tracking**: Create, manage, and track habits across various categories. ✅
- **Hydration Tracking**: Monitor your daily water intake and set reminders. 💧
- **Progress Visualization**: View your progress through charts and summaries. 📈

## Features ✨

- **Onboarding**: Guides new users through the app's core functionalities. 🚀
- **Authentication**: Sign-up, sign-in, and forgot password functionalities. 🔐
- **Habit Management**: Add, edit, delete, and track habits with categories and reminders. 🗓️
- **Mood Logging**: Record daily moods with emojis and notes. 📝
- **Hydration Tracking**: Log daily water intake and set goals. 💧
- **Progress Overview**: Visualize mood trends, hydration levels, and habit completion rates. 📊
- **Customizable Settings**: Edit profile details and manage notification preferences. ⚙️
- **Reminder Notifications:** Configurable reminders for hydration and habits. ⏰

## Tech Stack 💻

- **Kotlin**: Primary programming language. 📱
- **Android SDK**: For building the Android application. 🤖
- **Gradle**: Build automation tool. ⚙️
- **UI Components**: Material Components for Android.

## Installation ⚙️

1.  **Clone the repository**:
   ```bash
   git clone https://github.com/vihangi-jayasinghe/Aura-Habit-Tracker.git
   ```
2.  **Open the project in Android Studio**.
3.  **Build the project**:
   -  In Android Studio, go to `Build` > `Make Project`.
4.  **Run the application**:
   -  Connect an Android device or emulator.
   -  Click the `Run` button in Android Studio.
